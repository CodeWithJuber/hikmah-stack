# Lens: Memory Integrity

Ask these before trusting remembered context:

- Is this an observation, a belief, a preference, or a model-generated guess?
- What is the provenance and verification state?
- Is it scoped to the correct person/project/environment?
- Has a later correction superseded it?
- Is there a contradictory active claim?
- Did the associated action succeed, fail, or remain untested?
- Is the memory still relevant, or merely easy to retrieve?
- Is remembering it permissible under the privacy/retention policy?
