# Lens: Human Memory Inspiration Without Cargo Culting

Do not map software components to brain regions merely because the analogy sounds advanced.

Borrow only a principle that solves a measured engineering problem:

- **selectivity** -> bounded working set and suppression;
- **replay** -> offline consolidation proposals;
- **reconsolidation** -> versioned correction instead of overwrite;
- **temporal structure** -> sequence/deadline first-class fields;
- **distributed association** -> dynamic multi-cue resonance rather than one permanent link;
- **forgetting** -> accessibility decay separated from deletion;
- **prospective memory** -> explicit commitments/triggers;
- **procedural memory** -> durable playbooks/skills.

Then test the software mechanism on its own metrics. Biology is inspiration, not proof.
