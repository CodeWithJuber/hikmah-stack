# Playbook: Remember -> Recall -> Consolidate

Use this whenever an agent has durable memory available.

## Remember
1. Classify the trace: observation, episode, belief, procedure, commitment, preference, constraint, outcome, or correction.
2. Preserve provenance before compression.
3. Mark confidence separately from source authority.
4. Refuse secret/sensitive persistence unless the configured storage layer supports the required protection/deletion semantics.
5. If it is a structured claim, check for a competing active value.
6. Write the trace; never overwrite history in place.

## Recall
1. Name the current goal, not just keywords.
2. Activate from multiple cues: words, tags, time, salience, confidence, provenance, and commitment urgency.
3. Suppress redundant memories so the working set stays small.
4. Pull corrections/conflicts beside the claim they challenge.
5. Label recalled content by source and status before using it in a consequential decision.

## Consolidate
1. Replay outcomes and corrections, not only the original plan.
2. Look for repeated patterns across independent evidence.
3. Propose a belief/procedure; do not auto-promote it.
4. Preserve minority/conflicting evidence until resolved.
5. Turn repeated failure into a test, rule, or playbook change.
